# 🧳 Tokyo Shop — Travel & Luggage Store

A Python-based travel and luggage store project featuring Sakura-branded products.

## 📌 About the Project

Tokyo Shop is a beginner-friendly Python project that simulates a travel and luggage store. It organizes product information, including names, prices, stock quantities, colours, and descriptions.

## ✨ Features

- Product information management
- Product prices and stock quantities
- Available colours and product descriptions
- Structured product data using Python dictionaries

## 🛍️ Products

The project includes sample products such as:

- Sakura Backpack
- Sakura Handbag
- Sakura Suitcase

## 🛠️ Technologies

- **Language:** Python
- **Data structures:** Dictionaries and tuples

## 🚀 Getting Started

1. Install Python 3.
2. Clone or download this repository.
3. Open the project folder in your terminal.
4. Run the Python file:

   ```bash
   python Ahmeds_Python_Project.py
   ```

## 📚 Project Purpose

This project was created to practise Python programming, data organization, and the development of a simple store concept.
